Quines are self producing programs.

Quines are a fundamental property of all turing complete machines and languages.

As a person interested in the concept of recursion, quines have amazed me the first time i read about them. Altough, they are not exactly a recursion. Quines are like the ouroboros or the fractals of programming. They output the program code itself. Thus, the output is also a quine. 

There isn't a single possible quine per language like i thought it would be. I will be trying to write quines across all the programming languages that i feel confident with.
